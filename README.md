# Folio 书本翻页预览

双击 `index.html` 即可在浏览器中使用，无需安装依赖或启动服务器。

## 已实现

- 上传多张 JPG、PNG、WEBP 图片，也可直接拖放或粘贴图片
- 封面、封底、内页图片独立上传；末页固定作为封底预览
- 封面封底展开图上传：自动裁切左右两半用于封面和封底，单独上传的封面或封底优先
- 跨页大图上传：上传后作为占 2 页的内容项加入内页队列，并保留中央书脊阴影
- 普通内页与跨页大图混排：左侧列表可一起拖拽排序，跨页大图始终对齐到完整跨页
- 上传内容后自动计算总页数：封面、封面反面、封底反面、封底共 4 页，普通内页计 1 页，跨页大图计 2 页
- 书页顺序固定为：封面 → 封面反面纯空白 → 内页01单页 → 内页02–03跨页 → … → 封底反面纯空白 → 封底
- 封面反面和封底反面自动参与预览，但不会单独出现在页面拖拽列表中
- A4、A5、方形与任意自定义宽高（毫米）
- 自定义页数，封面单页、内页自动双页跨页
- 独立 3D 书籍视图：拖动旋转、滚轮缩放、双击或按钮回到正面
- 3D 书体厚度随页数变化，并显示纸张数量与估算毫米厚度
- 3D 封面、封底同步：首页作为封面，末页作为封底
- 3D 预览工作区左右固定显示完整封面和封底，不随内页翻页或模型旋转丢失
- 3D 模型内翻页、键盘翻页、全屏演示模式
- 左开本与右开本，自动切换跨页顺序、翻页方向和上一页/下一页按钮位置
- 标准、高清、60 线网点三种清晰度模式；2D/3D 页面均使用高分辨率画布渲染
- 60 线网点模式支持 4 倍悬停检查，3D 视图可继续放大查看
- 3D 页面纹理根据缩放和观察角度动态重采样，减少网点缩放产生的摩尔纹
- 预览区固定的上一页、下一页按钮
- 页面缩略图、拖拽重排、内页总览与快速跳转
- 单页/跨页预览、缩放、页边距、裁切参考线与纸张纹理
- 上、右、下、左四边距与出血距离均可按毫米独立设置
- 深色/浅色主题

## 隐私

图片通过浏览器本地 Blob URL 读取，不会上传到服务器。刷新页面后需要重新选择图片。

## 分享与部署

这是一个纯静态网站，不需要后端、数据库或安装命令。

### 发送单文件

把 `folio-book-preview.html` 直接发送给别人，双击即可在桌面浏览器中使用。样式和脚本已经全部包含在该文件中。

### 上传为网站

1. 解压 `folio-book-preview-share.zip`。
2. 把 `index.html`、`styles.css`、`app.js` 和 `README.md` 放在同一个目录。
3. 将整个目录上传到 Netlify、Cloudflare Pages、Vercel 或任意静态网站服务器。

也可以把压缩包直接拖入 Netlify Drop 或 Cloudflare Pages 的上传入口。

### GitHub Pages

1. 新建一个 GitHub 仓库。
2. 上传解压后的全部文件，确保 `index.html` 位于仓库根目录。
3. 打开仓库的 Settings → Pages。
4. 在 Build and deployment 中选择 Deploy from a branch，并选择 `main` 和 `/ (root)`。

部署完成后，GitHub 会提供一个可公开访问的网站链接。
